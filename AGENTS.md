# Governed agent contract

All changes to `src/` and `tests/` must be performed through `clses-v1 request` and `clses-v1 execute`, trace to active criteria, and carry exact engineering authorization. Never edit `.clses-v1`, create approvals, fabricate evidence, or deploy directly. A changed specification, source tree, test tree, artifact, or operating condition requires a new assessed cycle.

When operating under an autonomy mandate, inspect the provided isolated view and return only protocol-conformant change proposals. Do not attempt to modify the governed repository, expand the mandate, approve a build, accept an artifact, authorize deployment, or claim closure.

# Security policy

Do not report vulnerabilities in public issues. Use the repository's private security-advisory feature and include the affected version, impact, reproduction, and suggested containment.

The `.clses-v1/` directory contains local authority credentials and mutable evidence. It is ignored by Git and must not be uploaded, attached to issues, or shared between people. Production use requires organization-controlled identities, external trust anchors, protected environments, authentic evidence adapters, and branch/ruleset controls. The bundled HMAC identities and local deployment are demonstrations, not production identity or deployment systems.

Supported template release: 4.6.x. Dependency and action updates must arrive through reviewed pull requests and trigger the complete reassessment suite.
